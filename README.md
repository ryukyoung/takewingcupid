# 🪽 Take Wing, CUPID!

> **IVE의 정규 앨범 `IVE SECRET` 프로모션을 위해 제작한 팬메이드 2D 픽셀 아트 횡스크롤 게임**

**Take Wing, CUPID!**은 IVE의 `IVE SECRET` 앨범 프로모션을 목적으로 제작한 팬메이드 게임입니다. <br>
`XOXZ` 뮤직비디오의 분위기와 배경을 바탕으로 픽셀 아트 스타일의 횡스크롤 게임으로 제작했습니다.

<br>

## 🎮 Game

**6명의 캐릭터 중 하나를 선택하여 장애물을 피하고, 깨진 하트를 획득하며 게임을 진행해 보세요!**

* 👤 **플레이어 선택** — 6명의 캐릭터 중 하나를 선택
* 💔 **아이템 획득** — 깨진 하트를 획득하여 점수 획득
* 🧱 **고정 장애물** — 진행 경로에 배치된 장애물
* 💨 **이동 장애물** — 멀리서 갑작스럽게 날아오는 장애물
* 🏆 **점수 기록** — 획득한 하트에 따라 점수 집계
* 📤 **결과 공유** — 게임오버 화면에서 플레이 결과 공유

## 🕹️ How to Play

### 권장 환경

본 게임은 **횡스크롤 방식**으로 제작되었으므로 **가로 모드(Landscape)** 플레이를 권장합니다.

### 조작 방법

* **화면을 누르면** 캐릭터가 상승합니다.
* **화면에서 손을 떼면** 캐릭터가 하강합니다.
* 장애물을 피하면서 **깨진 하트 💔를 획득하여 높은 점수**에 도전해 보세요.
* 장애물에 충돌하면 게임이 종료됩니다.

> 💡 첫 화면은 프롤로그입니다. 화면을 터치하면 다음 화면으로 진행됩니다.

### Game Over

게임오버 화면의 **공유 버튼**을 통해 자신의 플레이 결과를 자유롭게 공유할 수 있습니다.

<br>

## 🔧 Technical Details

### Character Movement

화면 터치 상태에 따라 캐릭터의 상승 및 하강을 제어하여 직관적인 비행형 이동 시스템을 구현했습니다.

### Collision Detection

플레이어와 장애물 간의 충돌을 감지하여 충돌 발생 시 게임오버 상태로 전환되도록 구현했습니다.

### Game State

프롤로그, 게임 시작, 플레이, 게임오버 등 게임의 주요 상태를 관리하여 각 상태에 따른 화면과 동작을 구현했습니다.

### Obstacle & Item System

고정된 장애물과 이동 장애물을 구성하고, 게임 진행 중 깨진 하트를 획득할 수 있도록 게임 요소를 구현했습니다.
